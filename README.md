# What's for Dinner?

A small dinner-picker web app for phone and iPad.

- Spin up a dinner from pantry staples, with a shared protein and a one-serving recipe
- Cheat days with no plan (ideas optional)
- A 7-day plan you can reroll or reorder
- Shopping list split by grocery trip and grouped by aisle
- Trader Joe's heat-and-combine dinners on chosen days

Everything is in `index.html`. Data is saved in the browser on each device (localStorage), with no server.

Live app: https://alexarmstead.github.io/whats-for-dinner/
